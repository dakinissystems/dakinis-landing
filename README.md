## Local

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```

| Comando | Uso |
|---------|-----|
| `npm install` | Dependencias |
| `npm run dev` | Desarrollo |
| `npm run build` | Build estático `dist/` |
| `npm run preview` | Preview del build |

## Contenido
